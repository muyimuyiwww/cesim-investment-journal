## 每回合怎样更新

1. 从 Cesim 下载该回合的结果 XLS，保留原始结果工作表。
2. 在同一个 XLS 内加入“经济展望预测”工作表，记录当时的估计值、公布的实现值、误差和来源。回合 1 已补入 64 项市场板块预测／实现对照，以及 29 项宏观情景记录。宏观情景的“下回合页面上季度”只用于核对网页存档，不能当作真实实现值。
3. 根据该回合官网结果和上期策略写复盘，分开讨论证券本币收益、汇率、费用、组合回报和公司利润。反事实回测说明固定了哪些条件。
4. 讨论并记录新一期投资策略与持仓。每期结果揭晓后，新增该期的 XLS 和复盘，周报链接到相应文件。

## 预测数据口径

回合 1 的“经济展望预测”来自 Cesim 个人决策区“经济展望”页面所列的“上回合估计值”和“上回合实现值”。政府债券比较期末收益率，公司债比较信用利差，股票比较因子与行业回报；误差为实现减估计，单位是百分点。这些指标不能混成一种投资收益率。

网站历史页面没有拆分分析师原始建议与个人手动调整，因此目前检验的是决策时采用的预测输入，不能仅凭这一期误差评价分析师团队能力。以后若要单独评价分析师，需在调整之前保存分析师原始建议，再与最终输入和实现值对照。

现实市场价格不用于推断 Cesim 模拟器后续走势。官网页面仍需相应账号和回合权限；仓库中的 XLS 可直接下载查看。
