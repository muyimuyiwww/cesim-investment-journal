## 每回合怎样更新

1. **开始时冻结上回合证据。** 从 Cesim 下载结果 XLS，记录官网小组实际基金回报、公司利润和逐项资产结果；在新回合“经济展望”页面补录 XLS 未包含的“上回合估计值／实现值”。保留来源日期和口径。
2. **先复盘，再写新判断。** 对照上一期的投资策略与真实结果，分开评估证券本币回报、汇率、扣费后的基金回报和公司利润。反事实回测必须写清不变的费用、规模与收费假设。
3. **记录新回合的原始展望。** 在调整任何估计值前保存一个初始快照；讨论和修改完成后，再另存“最终提交前快照”。不能用事后数据覆盖当时预测。
4. **共同形成策略。** 从宏观与行业情景进入个券和四因子，再检查债券期限、信用利差、币种、行业和单股集中度。把个人方案与小组实际提交方案明确区分。
5. **发布周报。** 使用 [周报模板](templates/weekly.md)，链接当期策略、预测表和复盘。下回合结果揭晓后补实际值，并新建下一期记录。

## 数据口径

- [回合1预测对照 CSV](rounds/round-01/forecast_vs_actual.csv) 记录国债**期末收益率**、公司债**相对国债的利差**、股票因子及行业**总回报**、另类投资板块**总回报**。CSV 中的数值是百分数，误差是**实际减估计的百分点**；不同类别不应当混为一种收益率。
- [回合2初始展望 CSV](rounds/round-02/initial_outlook.csv) 于 2026-10-09 从个人决策区记录，状态为**草稿快照**，并非最终提交方案。其后任何修改要另存新版本。
- 经济基本面的 GDP、通胀、失业率、信心和汇率分别记录在[回合1宏观情景](rounds/round-01/macro_scenario.csv)与[回合2宏观情景](rounds/round-02/macro_scenario.csv)。回合1存档页的“本回合预期”和回合2页面的“上季度”逐项相同；这组网页情景值并非个人可编辑估计，不计入分析师预测评分。
- Cesim 的“上回合估计值”对应个人决策区最终输入，当前存档无法区分分析师原始建议和人工作出的改写。这里检验的是**当时使用的预测输入**，不能单凭一个回合的误差评价分析师团队能力。今后若要单独评价分析师，应在修改前保存其原始建议，再对照最终输入和实现值。
- 现实市场价格不能用于推断 Cesim 模拟器后续走势。历史有效前沿只作为历史样本统计，不当作模拟器未来回报预测。

公开仓库保留分析和必要的逐项派生数据。Cesim 原始导出 XLS 存在本地 `private/raw/`，不上传到公开仓库；复核官网页面仍需相应账号和回合权限。
